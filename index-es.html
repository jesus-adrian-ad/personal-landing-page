Proyectos

API Reactiva de Productos

Una API REST no bloqueante para la administración de productos, construida con endpoints funcionales de Spring WebFlux y Spring Data R2DBC sobre PostgreSQL. Toda la cadena — petición, servicio, base de datos — es reactiva de extremo a extremo.

Levanta su propia base de datos: al arrancar detecta el docker-compose.yml, inicia el contenedor de PostgreSQL, espera a que esté sano y se conecta. La API está documentada con OpenAPI 3.1 y se puede explorar desde Swagger UI.

  • Spring WebFlux
  • PostgreSQL
  • Docker
