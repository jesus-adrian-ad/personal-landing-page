Projects

Reactive Products API

A non-blocking REST API for product management, built with Spring WebFlux functional endpoints and Spring Data R2DBC over PostgreSQL. The whole chain — request, service, database — is reactive end to end.

It ships its own database: on startup it detects the docker-compose.yml, brings up the PostgreSQL container, waits until it's healthy and connects. The API is documented with OpenAPI 3.1 and browsable through Swagger UI.
